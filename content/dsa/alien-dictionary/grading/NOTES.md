# Grader notes: Alien Dictionary

Any valid order passes. When an order exists, the tests check that every character of the answer is a letter used in the words, that none repeats, that the answer has as many letters as the words use (so every letter appears, including letters no rule mentions), and that every neighbouring pair of words is sorted under it. When no order exists, the answer must be exactly the empty string; the comparison is on the quoted string.

Tests cover: the sample (Example 1, which has two valid answers; one word; a two-letter contradiction; a word before its own prefix); a prefix listed first (fine) and a longer word before its prefix inside a longer list (empty); `"bx"` then `"xb"`, where reading past the first difference invents x before b and wrongly returns the empty string; letters that no rule mentions, alone and in a list of words that are all prefixes of each other; repeated words, and the rule a before b given by two pairs (counting it twice in Kahn's algorithm leaves b waiting forever and wrongly returns the empty string); cycles through three letters; 200 seeded random lists sorted by a hidden order of 1 to 8 letters, each also checked with a word and then its own proper prefix appended (empty); and two lists of 100,000 words.

The two large tests have a limit of 1,000 ms each (3x is 3,000 ms). Each list is the numbers 0 to 99,999 written as four base-26 digits in a seeded, shuffled alphabet, so it is sorted and all 26 letters appear; in the second, the last number is replaced by a repeat of the first word, which demands that the first word's letter come after the last word's, a cycle. The reference, neighbouring pairs and Kahn's algorithm, finishes each well within the limit, including the test's own check of the answer. The naive solution compares every pair of words, about five billion comparisons, and times out on both tests, also at 3x. The walkthrough's Better, neighbouring pairs with repeated scans, is as fast as the reference here, since the scans cost at most 26³ steps; the tests deliberately do not separate them.
