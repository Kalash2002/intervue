## Level 1
Build a combination by taking values and subtracting them from what is still missing. Two equal values at different positions can each be taken. What does that do to the list of answers?

## Level 2
Equal values make the same combination come out more than once. If the array were sorted, what could you compare a value with to tell that it would only repeat work done a moment ago?

## Level 3
After sorting, at each step of choosing the next value, try each different value once: a later copy of the value just tried leads to the same combinations, while taking that copy after the first one is still allowed one step deeper.
