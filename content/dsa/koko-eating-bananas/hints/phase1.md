## Level 1
For one chosen speed, can you work out how many hours all the piles take? What happens to that number as the speed goes up?

## Level 2
Faster never takes longer, so the speeds split into a run that misses the limit followed by a run that meets it. You are looking for the first speed of the second run, and the largest pile's size is always in it.

## Level 3
Count the hours for a speed in a type that can hold the total of a slow speed over many large piles.
