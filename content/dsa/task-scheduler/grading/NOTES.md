# Grader notes: Task Scheduler

Tests cover: the sample (7), an empty list, a single job, no gap, enough kinds that no slot is idle (`PPQQR` with gap 1 returns 5), many kinds where the job count beats the frame length (`KKKLLLMMMNN` with gap 1 returns 11, not the frame's 7), kinds that tie for the highest count (`XXXYYY` with gap 3 returns 10, `QQQQQRRRRRS` with gap 3 returns 18), one dominant kind among many small ones (`TTTTTUVWXYZ` with gap 2 returns 13), a gap larger than the job count, and a large case of 100,000 identical jobs with gap 3,000, whose answer is above three hundred million slots. The statement's cap of 3,000 on `gap` keeps the answer within an `int`.

The naive solution simulates the printer one slot at a time, scanning all 26 kinds for the busiest one that is allowed to run. Its work grows with the answer, which here is about 300 million slots, so it exceeds the limit and 3x the limit. The reference counts the kinds and computes the answer in one pass over the jobs.
