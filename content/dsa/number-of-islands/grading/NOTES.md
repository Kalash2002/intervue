# Grader notes: Number of Islands

Tests cover: the sample, an empty array, all water, all land, a single land cell, a single row, land touching only at a corner (two islands), a ring that encloses water and a ring with an island inside it, a snake that is one island, and two large 1,000 x 1,000 grids (a serpentine island of about 500,000 cells, which overflows a naive recursive search, and a checkerboard of 500,000 one-cell islands).

No naive solution: time is not graded separately for this question (ADR 0008).
