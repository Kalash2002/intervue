# Grader notes: Unique Email Addresses

Tests cover: the three samples, an empty list and a single address, one address repeated, dots in the name (including two in a row), everything after the first `+` ignored (a second `+`, an empty tag, dots in the tag, a dot just before the `+`), dots in the domain kept, different names that stay different (`ab` and `ba`, and a plus that cuts a name short), the same name on different domains, and a large case of 100,000 addresses for exactly 70,000 mailboxes: address `i` reaches mailbox `i % 70000`, whose name is `mailbox` plus six letters spelling the number, written with dots in changing places and a `+ne.ws` tag on every third address, on one of two domains.

The naive solution keeps a list of the reduced addresses seen so far and searches it for each address. Measured with a cold JVM on the large test: reference 200 ms, naive 28.1 s, limit 2,000 ms (reference 10x under the limit, naive 4.7x past the 3x line of 6,000 ms). The reference uses a hash set.
