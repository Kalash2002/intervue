## Level 1
Write the grid's values out in the order you read them, row after row. What kind of sequence do you get?

## Level 2
That sequence is one sorted list of m * n values, so you can search it by halving. The grid only changes how you reach the value at a given place in the list.

## Level 3
A place in the list and a cell in the grid convert into each other with one division and one remainder; which grid dimension you divide by is what decides whether the conversion is right.
