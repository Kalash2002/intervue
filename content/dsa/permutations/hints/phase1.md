## Level 1
Build an ordering one position at a time. How many choices are there for the first position, and how many are left for the second?

## Level 2
At each position, any value not used yet may go there. How do you know which values are still free, and what must you restore after trying one so the next try sees the same free values?

## Level 3
Mark a value as used before going one position deeper and clear the mark when you come back, so every level of the search sees exactly the values its own prefix has not taken.
