## Level 1
Compare the new range with each existing one. Into how many kinds can the existing ranges fall, relative to the new range?

## Level 2
Some ranges end before the new one starts, some start after it ends, and the rest overlap it. Because the list is sorted, these three groups come in that order. What happens to the middle group?

## Level 3
Walk the list once. Copy ranges that end before the new one starts. Then, while ranges still reach the new one, stretch the new range to cover them. Add the stretched range, and then copy what is left.
