# Grader notes: Process Tasks Using Servers

Tests cover: both samples, one machine, more machines than jobs with a weight tie (lower number first), jobs that wait and then take machines in arrival order, a machine that frees at the very second a job arrives, identical machines, a heavy machine used only while the light one is busy, a case where finishing seconds pass the `int` range (an `int` solution treats a busy machine as free and picks machine 1 for job 3), and a large case of 200,000 jobs on 150,000 machines whose weights are a permutation of 1 to 150,000. There the first 150,000 jobs take the machines in weight order and each later job `j` takes the machine that job `j - 150,000` used, because that machine frees at exactly second `j`; the expected array is built from that rule without running any assignment code.

The naive solution scans every machine for every job. Measured with a cold JVM on the large test: reference 262 ms, naive 21.1 s, limit 2,500 ms (reference 9.5x under the limit, naive 2.8x past the 3x line of 7,500 ms). The reference uses a heap of free machines and a heap of busy ones.
