# Grader notes: Subsets

Results are compared after sorting each subset and then the list of subsets, because any order is allowed; a subset listed twice stays in the compared list twice, so repeats fail. Tests cover: the sample, a single value, the empty array (the answer is one empty subset; a version that skips the empty subset, or returns an empty list for an empty array, fails), values at the limits of the range, four values written out in full (16 subsets), and six and twelve values, where the test checks that there are exactly 2^n subsets, that each holds only values of `nums` without repeats, and that no subset appears twice, which together prove the list is complete. A version that adds its working list to the result without copying it ends with every entry equal (usually empty) and fails the sample.

No naive solution: time is not graded separately for this question (ADR 0008). Every correct approach costs O(n * 2^n), because the answer itself holds n * 2^(n-1) values; the walkthrough's bitmask brute force is as fast as the reference, so there is no slower correct version to time out. The largest test (12 values, 4,096 subsets) has a generous 2,000 ms limit only to catch a runaway loop.
