## Level 1
How deep is a single node? How does the depth of a tree relate to the depths of the two trees hanging below its root?

## Level 2
Count carefully: the answer counts nodes, not edges, so one node alone is 1. Then think about the input where every node has a single child, and what one call per node would do to the stack.

## Level 3
Instead of following paths down, take the tree one whole level at a time and count the levels.
