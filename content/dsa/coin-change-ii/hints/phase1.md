## Level 1
Choosing the next coin and then paying the rest counts the same handful once for every order it can be handed out in: 8 + 5 + 3 and 3 + 8 + 5 are one way. Find an order of choices that builds each handful exactly once.

## Level 2
Decide the coin values one at a time: how many coins of the first value, then how many of the second, and so on. After a few values have been decided, all that matters is which value comes next and how much is still owed.

## Level 3
If the totals are filled in for one coin value at a time, a value added later can never come before an earlier one in any way counted, so no handful is counted twice.
