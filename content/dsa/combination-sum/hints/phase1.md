## Level 1
Build a combination one value at a time and subtract each value from what is still missing. When the missing amount reaches zero you have an answer. Why might the same combination then appear more than once?

## Level 2
Choosing 3 then 5 and choosing 5 then 3 give the same combination. Can you pick a fixed order for the values inside a combination so each one can be built only one way?

## Level 3
Let each step choose only the current value or a later one in the list, never an earlier one; the same value may still be chosen again.
