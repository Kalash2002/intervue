## Level 1
List subsets as if every position were different and look at which ones come out twice. What do the repeated ones have in common?

## Level 2
A distinct subset is fixed by how many copies of each value it takes, not by which copies. If equal values sat next to each other, how could you make sure a given number of copies is chosen in only one way?

## Level 3
After sorting, when you choose which value goes next into a subset, try each different value once at that step: a later copy of the value just tried would only rebuild the same subsets.
