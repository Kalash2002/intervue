# Grader notes: Rotate Image

Same sizes and rules as the classic version (`1 <= n <= 20`, values from -1000 to 1000, a quarter turn clockwise in place). The statement fixes what "in place" means for the tests: the method is `void`, and when it returns the array that was passed in must hold the turned board. Every test checks the caller's own array after the call, cell by cell, and that it still has `n` rows of `n` tiles, so building a turned copy and assigning it to the parameter fails every test but the one where four turns give the original back (7 of 8). Writing the turned rows into `grid[r]` also leaves the caller's array holding the board, so it passes; the statement does not ask for more. The result is a single board, so there is only one correct output.

Tests cover: the sample (a 5 x 5 board with a centre that stays, a 2 x 2 board, and the forced 1 x 1 board); a 6 x 6 board with every value written out; two turns giving half a turn on the same board; four turns giving the original 7 x 7 board back; a 7 x 7 board checked against the turn built in a separate array; repeated values (a 2 x 2 board of two values, and a 5 x 5 board of one value, which must stay as it is); the largest board, 20 x 20; and 200 seeded random boards of sizes 1 to 20, each checked against the turn built in a separate array in the test.

The traps the walkthrough names, each run as a scratch variant: mirroring across the diagonal alone (fails 7 of 8); mirroring across the diagonal and then reversing the order of the rows, an anticlockwise turn (fails 5); swapping every pair instead of those above the diagonal, which swaps each twice (fails 6); the ring loop running over the whole side, which moves each corner twice (fails 7); moving tiles in place without holding one aside (fails 8); and the copy assigned to the parameter (fails 7). Looping over the rings up to and including `n / 2` is harmless and passes.

No naive solution: time is not graded separately for this question (ADR 0008). Every approach has to move each of the n² tiles, so the brute force, a turned copy written back, is O(n²) like the reference and only uses more memory; with `n` at most 20 there is no slower correct approach worth timing. The tests keep the default limit.
