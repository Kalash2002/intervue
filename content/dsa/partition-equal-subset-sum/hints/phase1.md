## Level 1
Handing out the heaviest items first does not always work. Start from what one pack must weigh if the split exists.

## Level 2
One pack must weigh exactly half the total, so the question is whether some of the items add up to that half. The weights are small, so the number of different totals a group can have is small too.

## Level 3
Whether a total can be made from the first i items depends only on which totals the first i - 1 items can make.
