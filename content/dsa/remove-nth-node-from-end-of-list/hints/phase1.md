## Level 1
To unlink a node you need the node just before it. How would you find that node if you knew the length of the list?

## Level 2
When the node to remove is the head, there is no node before it. How can you make that case look like every other one?

## Level 3
Two references that start together, with one sent `n` nodes ahead first, stay `n` nodes apart; when the front one reaches the last node, the back one is where you need it.
