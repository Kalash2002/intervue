# Contains Duplicate

Given an array of integers `nums`, decide whether any value occurs at two or more positions.

Implement `ContainsDuplicate.hasDuplicate(int[] nums)` in `ContainsDuplicate.java`. Return `true` if some value repeats and `false` if every value is different.

## Examples

- `nums = [7, 2, 9, 7]` returns `true`: 7 appears at positions 0 and 3.
- `nums = [1, 2, 3, 4]` returns `false`: all values differ.
- `nums = []` returns `false`: nothing can repeat in an empty array.

## Constraints

- 0 <= `nums.length` <= 300,000
- Values are any `int`, negative values included.
