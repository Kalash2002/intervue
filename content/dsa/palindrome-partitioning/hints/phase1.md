## Level 1
Every way to cut the string starts with a first piece, and that piece must be a palindrome. Once you have chosen it, what is left to solve?

## Level 2
Try each palindromic first piece in turn, then cut the rest of the string the same way, keeping the pieces chosen so far in one list. When the rest is empty, that list is one answer. Which test do you repeat many times on the same stretch of letters?

## Level 3
Whether a stretch is a palindrome depends only on its two end letters and the stretch just inside them, so all those answers fit in one table built before the search.
