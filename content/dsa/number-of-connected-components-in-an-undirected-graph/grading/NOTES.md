# Grader notes: Number of Connected Components in an Undirected Graph

Tests cover: the sample (a machine with no cable, and a loop of three that is one network); one machine and four machines with no cables; a loop of three cables among three machines (machines minus cables would give 0); the same cable listed three times; two cables into the same machine (a union-find that sets `parent[b] = a` on the raw machines, without finding the representatives, loses machine 0 here); groups that merge late, joined through cables between earlier groups; forty seeded random rooms with a planted number of networks, each built from random trees plus random loop cables, shuffled and with random cable direction; a line of 100,000 machines listed in order (a recursive search overflows the stack here); and a timing case of a line of 60,000 machines listed from the far end, plus one machine on its own.

The timing test has a limit of 600 ms (3x is 1,800 ms). The naive solution passes over the cables, pulling both ends of each to the smaller label, until a pass changes nothing; listed from the far end, the smallest label moves one machine per pass, so it needs about 60,000 passes. Measured on a cold JVM: reference 10 ms, naive 6.9 s. The 100,000-machine line has a limit of 1,000 ms; the naive settles it in one pass and passes.
