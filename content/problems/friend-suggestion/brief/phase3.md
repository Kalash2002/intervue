## Phase 3: the whole network

**Phase 3 tests** run on networks of **100,000 users** with about eight friends each:

1. Suggestions for 4,000 different users.
2. Degrees apart for a few pairs at opposite ends of the network.

Each test has a time limit. Read the tests and `Datasets` first and say how much of the network each call touches. You may change any class except the tests and `Datasets`.
