## Phase 3: huge lines

Some tools write a whole dependency tree on one line. **Phase 3 tests** check a single line of **2,000,000 characters** with brackets nested a million deep, and a log of 200,000 ordinary lines. Each test has a time limit.

Read the tests and `Datasets` first and say how many times your code looks at each character before you change anything. You may change any class except the tests and `Datasets`.
